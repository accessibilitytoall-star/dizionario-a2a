API Application Programming Interface
Significato
Un insieme di regole e protocolli che permette a due sistemi digitali di comunicare tra loro e scambiarsi dati in modo standardizzato.
Spiegazione semplice
È come un cameriere al ristorante: prende la richiesta del cliente (il sito), la porta in cucina (il server), e riporta il risultato (i dati). Il cliente non entra mai in cucina — usa solo il cameriere.
Contesto A2A — accessibilità e EAA
Le API vengono usate nei form di contatto, sistemi di prenotazione, chatbot e widget integrati nei siti. Se queste integrazioni non sono accessibili, creano barriere — anche se il resto del sito è conforme WCAG.
Chi usa questo termine
Sviluppatori web, CTO, product manager, fornitori di servizi digitali (mappe, pagamenti, chatbot, newsletter).
Quando viene usato
Quando si integra un sistema esterno nel sito: Google Maps, pagamenti online, form di prenotazione, chatbot, social login, invio email automatico.
Come si scrive
Api → errore comune (solo iniziale maiuscola) API · sempre tutto maiuscolo, è una sigla
Pronuncia
In italiano si legge lettera per lettera: A-P-I. In inglese la pronuncia è identica: eɪ-piː-aɪ. Non esiste una versione italiana del termine.
5 frasi per memorizzarla
  • Beatrice"Quando integri un widget di prenotazione di terze parti, stai usando un'API — e quella API deve essere accessibile quanto il resto del sito."
  • Beatrice"Le API sono trasparenti per l'utente, ma non per chi fa l'audit: ogni integrazione esterna è un punto critico da verificare."
  • Beatrice"Un sito può essere perfetto nel codice proprio, ma se usa un'API che restituisce HTML non strutturato, l'accessibilità crolla nel punto di congiunzione."
  • Neutrale"Un'API definisce come due sistemi si parlano: quali dati inviare, in quale formato, e come interpretare la risposta."
  • Neutrale"Le API REST sono le più diffuse nel web moderno: comunicano tramite HTTP e restituiscono dati in formato JSON."

backend lato server · back-end · server-side
Significato
La parte "dietro le quinte" di un sito o applicazione web — server, database e logica di funzionamento che l'utente non vede, ma che fa girare tutto. Si contrappone al frontend, la parte visibile.
Spiegazione semplice
È come la cucina di un ristorante: il cliente vede solo il piatto (il sito), ma dietro c'è tutta l'infrastruttura che prepara, conserva e serve i dati.
Contesto A2A — accessibilità e EAA
Nel lavoro di accessibilità, il backend genera il codice HTML delle pagine. Se produce codice mal strutturato — senza heading, senza attributo lang, senza aria-label — il sito fallisce i requisiti WCAG anche se graficamente sembra a posto.
Chi usa questo termine
Sviluppatori web, CTO, project manager digitali, consulenti IT, aziende con siti dinamici o e-commerce, chiunque lavori con CMS, API o database.
Quando viene usato
Quando si parla di sviluppo web, integrazione con CMS, form di contatto, database, performance del sito o API.
Come si scrive
bacend → errore comune backend · anche back-end (con trattino) è accettato
Pronuncia
In italiano si pronuncia quasi come in inglese: bèc-end (accento sulla prima sillaba). In inglese: bæk-end. Non esiste una traduzione italiana standard: lato server o server-side sono i sinonimi tecnici più diffusi.
5 frasi per memorizzarla
  • Beatrice"Il backend del tuo sito genera le pagine: se nasce già inaccessibile, nessun restyling lo salverà."
  • Beatrice"Ho trovato spesso siti belli in facciata ma con un backend che buttava fuori codice HTML disorganizzato — e lì cascava l'audit."
  • Beatrice"Quando parlo con gli sviluppatori, la prima domanda è sempre: cosa gira nel backend?"
  • Neutrale"Il backend gestisce tutte le operazioni che l'utente non vede: autenticazione, database, logica di calcolo."
  • Neutrale"Un backend ben strutturato produce HTML semantico — fondamentale per le tecnologie assistive come gli screen reader."

CMS Content Management System
Significato
Sistema software che permette di creare, gestire e pubblicare contenuti su un sito web senza scrivere codice manualmente.
Spiegazione semplice
È il "pannello di controllo" del sito: si aggiungono testi, immagini, pagine e articoli tramite un'interfaccia visiva, senza toccare il codice. WordPress, Wix, Squarespace, Shopify sono tutti CMS.
Contesto A2A — accessibilità e EAA
Il CMS determina quali funzionalità di accessibilità sono disponibili: se supporta heading gerarchici, testi alternativi per le immagini, campi ARIA. Un CMS accessibile facilita la conformità EAA; uno inadatto la sabota strutturalmente.
Chi usa questo termine
Marketing manager, content editor, SEO specialist, web designer, proprietari di siti che non sanno programmare.
Quando viene usato
Quando si parla di gestione dei contenuti del sito, aggiornamento di pagine, blog, e-commerce, o scelta della piattaforma per un nuovo sito.
Come si scrive
cms → errore comune (minuscolo) CMS · sempre tutto maiuscolo, è una sigla
Pronuncia
In italiano si legge lettera per lettera: C-M-S. In inglese la pronuncia è identica: siː-ɛm-ɛs. Non esiste una traduzione italiana standard del termine.
5 frasi per memorizzarla
  • Beatrice"Il CMS è dove si combatte davvero la battaglia dell'accessibilità quotidiana: se non supporta i testi alternativi, nessuno li inserirà."
  • Beatrice"Ho visto siti tecnicamente accessibili rovinati da un CMS che sovrascriveva heading e alt text ad ogni aggiornamento."
  • Beatrice"Scegliere il CMS giusto è già metà del lavoro di accessibilità — prima ancora di scrivere una riga di codice."
  • Neutrale"Un CMS permette a chi non conosce il codice di aggiornare il sito tramite un'interfaccia grafica — come un editor di testo avanzato."
  • Neutrale"WordPress alimenta circa il 43% dei siti web mondiali ed è il CMS più diffuso, con migliaia di plugin tra cui diversi dedicati all'accessibilità."

EAA European Accessibility Act · Atto Europeo sull'Accessibilità
Significato
Direttiva europea (n. 2019/882) che obbliga le aziende che offrono prodotti e servizi digitali nel mercato UE a renderli accessibili. In Italia è stata recepita con il D.Lgs. 82/2022. La scadenza per i nuovi servizi è il 28 giugno 2025; per i servizi già esistenti al 28 giugno 2025, si può chiedere una proroga fino al 2030 dimostrando onere sproporzionato.
Spiegazione semplice
È la legge europea che dice: "se vendi un servizio digitale nell'UE, deve essere usabile anche da persone con disabilità." Non è una raccomandazione — è un obbligo legale. Chi non si adegua rischia sanzioni amministrative.
Contesto A2A — il core business di Beatrice
L'EAA è il motivo per cui esiste AccessibilityToAll SRL. Beatrice aiuta le PMI — soprattutto nel settore hospitality, moda e manifattura con servizi digitali — a comprendere gli obblighi EAA, fare un audit WCAG e ottenere la conformità prima che scattino le sanzioni. Il contratto tipo è: Diagnosi EAA €350 + contratto annuale di conformità garantita €10.000/anno.
Chi usa questo termine
CEO e responsabili legali di aziende con siti, app o chioschi digitali rivolti al pubblico UE; consulenti di accessibilità; avvocati specializzati in compliance digitale; autorità di controllo.
Quando viene usato
Quando si parla di obblighi di accessibilità digitale per le aziende, di audit WCAG in ottica legale, di dichiarazione di conformità, o di rischio sanzioni per siti non accessibili dopo giugno 2025.
Come si scrive
eaa → minuscolo EAA · sempre tutto maiuscolo, è una sigla
Pronuncia
In italiano lettera per lettera: E-A-A (e-a-a). Non esiste una pronuncia inglese diffusa in Italia per questa sigla.
5 frasi per memorizzarla
  • Beatrice"L'EAA non è una raccomandazione: è una legge. Dal 28 giugno 2025, un sito non accessibile espone l'azienda a sanzioni concrete."
  • Beatrice"Ho spiegato l'EAA a più di 200 imprenditori: la maggior parte non ne aveva mai sentito parlare — e i loro siti erano tutti non conformi."
  • Beatrice"L'EAA vale per e-commerce, siti di prenotazione, app, chioschi, sportelli digitali: se ha un'interfaccia utente e si trova nel mercato UE, è obbligato."
  • Neutrale"L'EAA chiede conformità ai requisiti WCAG 2.1 livello AA come standard tecnico di riferimento per la verifica dell'accessibilità."

frontend lato client · front-end · client-side
Significato
La parte visibile di un sito o applicazione web — tutto ciò che l'utente vede e con cui interagisce: layout, colori, testi, pulsanti, form. Si contrappone al backend, la parte invisibile.
Spiegazione semplice
È la sala del ristorante: il cliente vede e usa tutto — tavoli, menu, camerieri. Il frontend è ciò che appare nel browser, mentre il backend (la cucina) rimane nascosto.
Contesto A2A — accessibilità e EAA
Il frontend è la prima linea dell'accessibilità: contrasto dei colori, dimensioni del testo, etichette dei pulsanti, ordine di focus per la tastiera — tutto ciò che uno screen reader o un utente con difficoltà motorie incontra direttamente.
Chi usa questo termine
Web designer, sviluppatori frontend, UX/UI designer, consulenti di accessibilità, project manager digitali.
Quando viene usato
Quando si parla di design del sito, user experience, audit visivo, adattamento mobile, componenti interattivi (form, menu, modal).
Come si scrive
front end → errore comune (con spazio) frontend · anche front-end (con trattino) è accettato
Pronuncia
In italiano si pronuncia quasi come in inglese: front-end (accento sulla prima sillaba, "o" aperta). In inglese: frʌnt-ɛnd. Non esiste una traduzione italiana standard: lato client o client-side sono i sinonimi tecnici più diffusi.
5 frasi per memorizzarla
  • Beatrice"Il frontend è la prima cosa che l'utente tocca: se non è accessibile, nessuna funzionalità del backend salverà l'esperienza."
  • Beatrice"Spesso mi mostrano il frontend perfetto — animazioni, colori, font curati — e poi nell'audit trovo contrasto insufficiente e zero etichette ARIA."
  • Beatrice"Il frontend è la vetrina: bella ma vuota non basta."
  • Neutrale"Il frontend è sviluppato con HTML, CSS e JavaScript e determina l'aspetto visivo e l'interattività del sito."
  • Neutrale"Un frontend accessibile rispetta WCAG 2.1 AA: contrasto minimo 4.5:1, testo scalabile, navigazione completa da tastiera."

LLM Large Language Model · modello di linguaggio di grandi dimensioni
Significato
Tipo di modello di intelligenza artificiale addestrato su enormi quantità di testo per comprendere e generare linguaggio naturale. È il motore che alimenta strumenti come ChatGPT, Claude, Groq e Gemini.
Spiegazione semplice
È come un archivio di tutta la scrittura umana che ha "imparato" a rispondere, scrivere e ragionare leggendo miliardi di pagine. Non "capisce" come un essere umano, ma è straordinariamente bravo a completare testo in modo coerente e utile.
Contesto A2A — vibecoding e tool AI
Tutti i tool AI usati da Beatrice — Claude (Anthropic), Groq (Llama/Mixtral), ChatGPT (OpenAI) — sono basati su LLM. Comprendere cosa sono e come funzionano aiuta a usarli meglio: prompt più precisi, risultati migliori, meno token sprecati.
Chi usa questo termine
Sviluppatori AI, ricercatori, giornalisti tech, manager che valutano soluzioni AI per la propria azienda, chiunque lavori con strumenti di intelligenza artificiale generativa.
Quando viene usato

Come si scrive
llm → minuscolo LLM · sempre tutto maiuscolo, è una sigla
Pronuncia

Quando un progetto è pronto per essere condiviso online: si collega il repository GitHub a Vercel e ogni push aggiorna il sito in automatico. Ideale per prototipi, MVP, siti statici e app Next.js.
Come si scrive
Vercel (con la V maiuscola, è un nome proprio)
vercel (accettabile in contesti tecnici, es. comandi da terminale)

WCAG Web Content Accessibility Guidelines · Linee Guida per l'Accessibilità dei Contenuti Web
Significato
Standard internazionale pubblicato dal W3C (World Wide Web Consortium) che definisce i requisiti tecnici per rendere i contenuti web accessibili a persone con disabilità visive, uditive, motorie e cognitive. La versione di riferimento per l'EAA è WCAG 2.1 livello AA.
Spiegazione semplice
È il "codice di costruzione" dell'accessibilità web: una lista di criteri tecnici che un sito deve rispettare per essere usabile da tutti. Come il codice edilizio per gli edifici fisici, ma per i siti web. Il livello AA è quello obbligatorio per legge (EAA).
Contesto A2A — il cuore tecnico del lavoro
Le WCAG 2.1 AA sono lo standard tecnico su cui si basa tutto il lavoro di audit di AccessibilityToAll. Beatrice verifica criterio per criterio: contrasto colori (1.4.3), testi alternativi (1.1.1), navigazione da tastiera (2.1.1), etichette form (1.3.1), heading strutturati (1.3.1). Ogni output visivo — cruscotti, demo, landing page — deve rispettare queste linee guida.
Chi usa questo termine
Consulenti di accessibilità, sviluppatori web, UX designer, responsabili di conformità, avvocati specializzati in compliance digitale, titolari di siti con obbligo EAA.
Quando viene usato
Quando si parla di audit di accessibilità, dichiarazione di conformità, correzione di barriere, formazione sul design inclusivo, o verifica di un sito rispetto agli obblighi EAA.
Come si scrive
wcag → minuscolo WCAG · sempre tutto maiuscolo; i livelli si scrivono A, AA, AAA
Pronuncia
In italiano lettera per lettera: W-C-A-G (doppiavu-ci-a-gi). In inglese: dʌb(ə)ljuː-siː-eɪ-dʒiː. Alcune persone pronunciano come parola: "wee-kag" — meno formale ma diffuso.

♿ Fondamento tecnico dell'EAA
Le WCAG 2.1 AA sono lo standard tecnico di riferimento dell'EAA. La conformità si dimostra verificando i criteri WCAG e producendo una dichiarazione di accessibilità — il documento legale che attesta la conformità al D.Lgs. 82/2022.
